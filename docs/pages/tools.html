嵌入式工具链 ​

日常开发用到的编译、调试、仿真、分析工具

开发环境 ​

  • Keil：STM32/LPC 等 ARM 开发
  • VS / Cursor：代码编辑、Qt 上位机
  • ESP-IDF：ESP32 开发

编译/调试工具 ​

  • GCC / ARMCC：交叉编译工具链
  • J-Link / Ozone：调试器、 trace 分析
  • OpenOCD：开源调试

仿真/分析工具 ​

  • CANoe / CANalyzer：CAN 总线分析
  • Wireshark：网络抓包
  • STM32CubeMX：引脚配置、时钟树

版本管理 ​

  • Git：代码版本控制
  • SVN：企业环境、批处理流程
  • Pingcode：项目管理、需求跟踪

其他 ​

  • PADS：原理图、PCB 绘制
  • 逻辑分析仪、示波器
