登录与单点登录（Sequence）

设备 B 登录同账号后，设备 A Token 失效，心跳 401 后强制退出。

sequenceDiagram
  participant A as 设备A
  participant S as 服务器
  participant B as 设备B
  A->>S: POST /auth/login
  S->>S: rotate nonce+version
  S-->>A: Token sid=N1 sv=1
  B->>S: POST /auth/login 同账号
  S->>S: rotate nonce+version
  S-->>B: Token sid=N2 sv=2
  A->>S: GET /auth/me 心跳
  S-->>A: 401 已在其他设备登录
  A->>A: 清会话回登录页
  B->>S: 业务 API
  S-->>B: 200 OK

登录失败锁定（Activity）

flowchart TD
  Start([输入账号密码]) --> Check{是否开发者}
  Check -->|是| Auth{密码正确}
  Check -->|否| Frozen{仍在冻结期}
  Frozen -->|是| Deny1[403 请稍后重试]
  Frozen -->|否| Auth
  Auth -->|是| Clear[清零失败次数] --> Rotate[轮换 SSO] --> OK[进入系统]
  Auth -->|否| Inc[失败次数加1]
  Inc --> Limit{达到10次}
  Limit -->|是| Lock[冻结约30分钟]
  Limit -->|否| Deny2[401 还可尝试]

三类 Agent 调用流程（Activity）

问答 / 故障 / 评审：鉴权 → RAG → LLM → 落库 → 记用量

flowchart LR
  U[用户提问] --> Auth{已登录且有权限}
  Auth -->|否| E403[403 或游客提示]
  Auth -->|是| Sess[绑定本人 session]
  Sess --> RAG[TF-IDF 检索按角色过滤]
  RAG --> LLM[LLM 或 Mock]
  LLM --> Save[写入业务表]
  Save --> Usage[usage_events]
  Usage --> UI[返回前端]

知识库入库（Activity）

flowchart TD
  Up[上传文件] --> Type{类型允许}
  Type -->|否| Err[400]
  Type -->|是| Perm{分类权限}
  Perm -->|否| E403[403]
  Perm -->|是| Parse[extract_text]
  Parse --> Chunk[chunk_text]
  Chunk --> DB[("documents + chunks")]
  DB --> Rebuild[rag.rebuild]
  Rebuild --> Done[已入库]
  View[有权限用户] --> Preview[preview]
  View --> Download[download]

核心表

  • users（SSO / 锁定字段）
  • documents / chunks
  • chat_sessions / messages
  • fault_cases / reviews
  • usage_events / activities

关键约束

  • 会话按 user_id 隔离
  • SSO 后登录挤掉旧设备
  • 游客禁知识库/故障/评审
  • 开发者删前自动备份
  • 默认重置密码＝账号名+123
