全部内网本地部署，数据不上外网。每层职责清晰，松耦合。

▾
第2层 · 后端服务层
FastAPI 文档解析/切片 向量化服务 日志解析 RAG检索 对话管理
▾
第1层 · 数据存储层
MySQL 8.0 FAISS向量库 本地文件服务器 Redis缓存
前端交互层
Web页面访问。
Agent核心层
LangChain编排6大专属Agent，本地大模型推理，仅基于公司内部资料作答。
后端服务层
FastAPI提供API，负责文档入库、向量化、日志解析、RAG检索、上下文管理。

二、6大仪器专属智能Agent

系统根据用户问题自动切换Agent，每个Agent专精一个技术方向。

🔧 软件架构Agent
三层架构解读、需求评审、开发方案、协议设计、迭代风险分析
🔬 故障诊断Agent
日志分析、报错定位、层级判定、根因分析、排查步骤、历史故障匹配
⚡ 硬件电路Agent
MCU、CAN、电源、驱动、采样、硬件接口、硬件故障分析
🔩 机械液路Agent
传动、泵阀、吸样、洗针、液面探测、机械卡顿故障分析
💡 光学检测Agent
发光值异常、本底、噪声、光路污染、增益异常、PMT参数
🧪 测试/临床/售后Agent
测试用例生成、回归范围、临床问题、现场排障方案、维修SOP
