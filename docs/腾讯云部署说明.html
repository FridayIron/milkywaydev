腾讯云 COS 部署说明 ​

域名：milkywaydev.cn

一、本地开发 ​

bash
npm run dev

浏览器访问 http://localhost:5173（端口以终端输出为准）。

二、构建并部署到腾讯云 COS ​

1. 构建 ​

bash
npm run deploy

构建结果输出到 docs/ 目录。

2. 上传到 COS ​

将 docs/ 目录下的所有文件上传到存储桶根目录（或你配置的静态网站目录）。

  • 控制台上传：腾讯云控制台 → 对象存储 → 选择存储桶 → 上传 docs 内所有文件
  • 或使用 COS 命令行工具批量上传

三、日常更新 ​

每次修改内容后：

bash
npm run deploy

然后重新上传 docs/ 到 COS（可覆盖已有文件）。
