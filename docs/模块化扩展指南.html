嵌入式博客 - 模块化扩展指南 ​

用嵌入式工程师能听懂的逻辑，拆解、修改、扩展这个博客

一、核心结论：你完全可以自己编辑所有模块 ​

操作对应文件难度
改门户大模块.vitepress/theme/portal-modules.js（左右大系统入口）★
改文字/内容直接改 pages/*.md★
新增博客npm run new:blog "标题" + 编辑生成的 md★
加图片放 public/assets/img/，md 里写 ![描述](/assets/img/xxx.jpg)★
加/删内容页改 .vitepress/config.mjs 菜单，新建 .md，并在 portal-modules.js 加入口★★
改技能星图改 pages/skill.md 的 frontmatter★★
改动画/样式改 .vitepress/theme/custom.css★★★

二、推荐编辑方式 ​

方式 A：Cursor / VS Code（当前） ​

  1. 左侧打开要改的 .md 文件
  2. 按 Ctrl+Shift+V（Mac: Cmd+Shift+V）打开 Markdown 预览，可边写边看效果
  3. 或右键文件名 →「打开预览」

方式 B：快捷命令 ​

bash
# 新建一篇博客（自动生成模板）
npm run new:blog "STM32 入门笔记"

# 本地实时预览
npm run dev

三、手把手操作步骤 ​

1. 新增一篇博客 ​

bash
npm run new:blog "我的第一篇文章"

会生成 pages/blog/2024-xx-xx-我的第一篇文章.md，直接编辑即可。

加图片：把图片放到 public/assets/img/blog/，在 md 里写：

markdown
![图片说明](/assets/img/blog/图片名.jpg)

编辑完后，到 pages/blog/index.md 的「文章列表」中添加链接：

markdown
- [我的第一篇文章](/pages/blog/2024-xx-xx-我的第一篇文章)

2. 修改已有模块内容 ​

例如给 pages/tech.md 加「PCB 设计」模块：

打开 pages/tech.md，在末尾加：

markdown
## 7. PCB设计
- Altium Designer
- 四层板 Layout
- EMI/EMC 整改
- 电源设计

保存后 npm run dev 会实时更新。

3. 加新模块（如「个人创新项目」） ​

步骤 1：在 pages/ 下新建 innovation.md

步骤 2：打开 .vitepress/config.mjs，在 sidebar 和 nav 里加：

js
{ text: '个人创新', link: '/pages/innovation' }

侧边栏和顶栏就会多出该选项。

4. 改技能星图 ​

打开 pages/skill.md，修改 frontmatter（文件开头的 --- 之间）：

yaml
indicator:
  - { name: 'C/C++', max: 10 }
  - { name: 'STM32', max: 10 }
  # ... 想加什么技能直接加
  - { name: 'PCB设计', max: 10 }   # 新增
  - { name: '工具链', max: 10 }    # 新增

skillValue: [9, 9, 8, 6, 7, 5, 7, 8]  # 对应上面维度的分数

5. 加代码 / 图片 / 视频 ​

① 加代码：Markdown 代码块，支持 C/C++ 等高亮

markdown
```c
#include "stm32f10x.h"
void GPIO_Config(void) { ... }
```

② 加图片：放到 public/assets/img/，引用：

markdown
![STM32开发板](/assets/img/stm32_board.jpg)

③ 加视频：

  • 小视频：放 public/assets/video/，用 <video> 标签
  • 大视频：传 B 站，复制嵌入代码：
markdown
<iframe src="https://player.bilibili.com/player.html?aid=xxx&bvid=BVxxx&cid=xxx&page=1" 
        width="100%" height="400" frameborder="0" allowfullscreen></iframe>

6. 改动画/样式 ​

打开 .vitepress/theme/custom.css，已有「渐入上滑」动画，可修改：

css
/* 改动画时长 */
animation: fadeIn 0.5s ease-in-out;  /* 0.5s 改为 1s 等 */

三、与嵌入式开发的对应关系 ​

操作对应嵌入式逻辑
改 .md 内容修改固件里的配置参数
加/删菜单给 MCU 加/减外设驱动
改技能星图改传感器数据采集维度
加图片/视频/代码给项目加外设（屏/摄像头）
改动画/样式优化固件的交互逻辑

图片存放位置 ​

用途路径
博客配图public/assets/img/blog/
页面插图（关于我、项目等）public/assets/img/pages/

引用格式：![描述](/assets/img/blog/文件名.jpg)

四、常用命令 ​

bash
npm install           # 首次或依赖变更后
npm run dev           # 本地开发，浏览器访问 http://localhost:5173
npm run new:blog "标题"  # 新建博客文章
npm run deploy        # 构建 + 输出到 docs/（上传到腾讯云前执行）
npm run preview       # 预览构建结果
