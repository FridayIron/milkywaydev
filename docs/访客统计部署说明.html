访客统计功能 - 方案 B 部署说明 ​

访客记录存储在您自己的 Cloudflare Worker + KV 中，仅您通过管理员密钥可查看。

一、创建 Cloudflare 账号 ​

  1. 访问 https://dash.cloudflare.com 注册
  2. 免费版即可

二、部署 Worker ​

1. 安装 Wrangler ​

bash
cd visitor-api
npm install

2. 登录 Cloudflare ​

bash
npx wrangler login

按提示在浏览器中完成登录。

3. 创建 KV 命名空间 ​

bash
npx wrangler kv namespace create VISITS

记下输出中的 id（如 xxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx）。

4. 修改 wrangler.toml ​

打开 visitor-api/wrangler.toml，将 REPLACE_WITH_YOUR_KV_ID 替换为上一步的 id。

5. 设置管理员密钥 ​

bash
npx wrangler secret put ADMIN_KEY

按提示输入一个强密码（如随机生成的字符串），此密码用于访问管理后台，请妥善保存。

6. 部署 ​

bash
npx wrangler deploy

记下部署成功后的 Worker 地址，如：https://visitor-api.xxx.workers.dev

三、配置网站 ​

编辑 .vitepress/visitor-api-url.js：

js
export const visitorApiUrl = 'https://visitor-api.xxx.workers.dev'  // 替换为你的 Worker 地址

四、重新构建并部署网站 ​

bash
npm run deploy
# 然后按你的部署方式推送 docs 或发布

五、使用 ​

  • 访客：正常浏览网站，每次访问会静默上报（无感知）
  • 管理员：访问 你的站点/pages/admin（如 https://milkywaydev.cn/pages/admin），输入步骤 2.5 中设置的 ADMIN_KEY 查看访客记录

管理页不显示在导航栏中，需通过直接输入链接访问。

收集的访客信息 ​

字段说明
时间访问时间戳
IP访客 IP（由 Cloudflare 获取）
访问页面当前页面 URL
来源Referer（从哪跳转来）
浏览器User-Agent
分辨率屏幕宽高
语言/时区浏览器语言、时区

注意事项 ​

  • 最多保留 5000 条记录，超出自动清理
  • 请勿将 ADMIN_KEY 泄露或提交到代码仓库
  • 访客无法访问管理后台，仅有密钥可查看数据
