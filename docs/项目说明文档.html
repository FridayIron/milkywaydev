三、常见修改操作 ​

3.1 修改简历（关于我） ​

文件：pages/about.md

直接编辑，可修改：

  • 基本信息：姓名、职业、籍贯、现居、工作年限、主攻方向
  • 联系方式：电话、邮箱
  • 工作经历：用 Markdown 表格，列：公司 | 时间 | 职位 | 主要工作
  • 关键业绩：用列表写亮点成果
  • 教育经历：学校、专业、届别、奖学金等
  • 竞赛获奖：表格，列：赛事 | 角色 | 成绩
  • 自我评价：一段话总结

表格示例：

markdown
| 公司 | 时间 | 职位 | 主要工作 |
|------|------|------|----------|
| 公司A | 2023.08 - 至今 | 工程师 | 工作内容 |

3.2 新增 / 删除导航菜单项 ​

文件：.vitepress/config.mjs

在 nav 和 sidebar 数组里添加或删除，例如：

js
{ text: '新页面', link: '/pages/newpage' }

同时需要在 pages/ 下新建对应 newpage.md。

3.3 修改首页标题与入口卡片 ​

文件：index.md

修改 frontmatter（文件开头的 --- 之间）：

yaml
hero:
  name: 王桥的技术博客    # 大标题
  text: 朝着极客方向前进   # 副标题
  tagline: 三年+ 嵌入式开发，持续记录，持续成长
  actions:
    - text: 进入博客主页
      link: /pages/about   # 按钮跳转
features:                  # 三个卡片
  - title: 项目经验
    details: 描述文字
    link: /pages/projects
  # ...

3.4 修改技能星图 ​

文件：pages/skill.md

修改 frontmatter：

yaml
indicator:                  # 技能维度
  - { name: 'C/C++', max: 10 }
  - { name: 'RTOS', max: 10 }
  # 加新维度就加一行

skillValue: [9, 9, 8, 7, 9]  # 每个维度分数 1-10

注意：indicator 有几项，skillValue 就要有几个数字。

3.5 新增博客文章 ​

bash
npm run new:blog "文章标题"

会生成 pages/blog/yyyy-mm-dd-文章标题.md。

  1. 编辑该文件写内容
  2. 在 pages/blog/index.md 的「文章列表」中添加上面这篇文章的链接

3.6 添加图片 ​

  1. 把图片放到 public/assets/img/blog/（博客）或 public/assets/img/pages/（其他页面）
  2. 在 Markdown 中写：
markdown
![图片说明](/assets/img/blog/图片文件名.jpg)

3.6a 添加网页小工具 ​

  1. 把 HTML 工具文件放到 public/tools/（如 png_to_svg.html）
  2. 在 pages/skill-tools.md 相应分类下添加介绍和链接：[工具名称](/tools/文件名.html)

3.7 修改网站标题 / 描述 ​

文件：.vitepress/config.mjs

js
title: '王桥 | 嵌入式工程师技术博客',
description: '工作经历 | 项目经验 | 技术积累 | 嵌入式基础小知识 | 个人创新',

3.8 访客统计管理后台 ​

若已部署 Cloudflare Worker 访客统计，可访问 /pages/admin 查看统计数据（该页面未出现在导航中）。

四、常用命令 ​

命令作用
npm install首次或依赖变更后安装依赖
npm run dev本地开发，浏览器访问 http://localhost:5173
npm run new:blog "标题"新建博客文章
npm run deploy构建并输出到 docs/（发布前执行）
npm run preview预览构建结果

五、发布流程 ​

  1. 本地修改内容
  2. 运行 npm run deploy（会重新构建并把结果写入 docs/）
  3. 提交并推送到 GitHub（包含 docs/），让 GitHub Pages 使用最新静态文件
    • 若线上菜单或页面与本地不一致，多半是未推送最新构建或浏览器/CDN 缓存；可尝试无痕窗口或稍后重试。
  4. 若仍使用腾讯云 COS：将 docs/ 下全部文件上传到存储桶
  5. 访问站点查看效果

六、技术栈说明 ​

  • VitePress：静态站点框架，基于 Vue 3 + Vite
  • Markdown：内容用 .md 编写，支持代码高亮、表格、图片
  • ECharts：技能雷达图
  • 腾讯云 COS：静态网站托管
  • 访客统计：Cloudflare Worker + KV（可选，需能访问 Cloudflare）

七、注意事项 ​

  1. 为减少浏览器控制台 Hydration mismatch 报错，站点已关闭 VitePress 默认的「深浅色切换」（appearance: false），首页宇宙背景仅在客户端挂载（ClientOnly）。若需要恢复主题色开关，可在 config.mjs 改回 appearance: true，但可能再度出现水合警告。
  2. 不要改：node_modules/、.vitepress/cache/、docs/（docs 会被 deploy 覆盖）
  3. 图片路径：必须放在 public/ 下，引用时以 / 开头，如 /assets/img/blog/xxx.jpg
  4. 新建页面：除了新建 .md，还要在 config.mjs 的 nav 和 sidebar 里添加链接
  5. Markdown 预览：在 Cursor/VS Code 中按 Ctrl+Shift+V 可边写边看效果
