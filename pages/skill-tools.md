# 个人项目与工具

这里收录我开发的一些实体项目，包括网页小工具、Python 界面工具等，方便自己使用，也分享给大家。

## 网页小工具

### SVG 转换工具

**PNG 转 SVG 在线转换工具**（精准比例输出）

- 支持 PNG 上传，等比例适配或强制尺寸输出
- 可设置输出 SVG 文件大小限制（50KB~无限制）
- 适配 LVGL 等嵌入式 UI 场景，转换后可配合 image converter-lvgl 转 C 数组
- 所有操作均在本地完成，不上传图片

**[打开 SVG 转换工具](/pages/skill-tools-svg)** ← 点击直达工具页面

### MCU MSP/PSP 上下文切换演示

**可视化 MCU 上电、MSP/PSP 栈切换与中断返回流程**

- 覆盖复位、裸机运行、RTOS 启动、中断触发、任务切换、恢复执行全流程
- 通过寄存器面板与双栈视图直观查看上下文变化
- 适合讲解 Cortex-M 栈模型与 RTOS 切换机制

**[打开 MCU 上下文切换演示](/pages/skill-tools-mcu-core)**

### 步进电机曲线计算器（图表版）

**多种加减速曲线 + 实时图表展示**

- 支持 S 曲线、梯形、线性、二次、三次、正弦、指数等曲线
- 同时展示速度曲线与定时器周期，便于参数调优
- 快速验证不同曲线下的动态效果

**[打开步进电机图表版工具](/pages/skill-tools-step-motor-view)**

### 步进电机加减速计算器（高级版）

**可自定义加速/减速公式，支持导出加速段参数表**

- 支持预设曲线与公式自定义测试
- 输出加速段台阶参数、频率与定时器周期
- 支持 CSV 导出，便于下位机参数落地

**[打开步进电机高级版工具](/pages/skill-tools-step-motor)**

## 本地联调系统

### IVD Agent 助手

**嵌入式/IVD 场景下的知识库问答与多 Agent 辅助平台**（前后端一体，需本机启动服务）

- 知识库检索、对话、故障/评审/报告等模块
- 本机运行：在 `3.AgentAssit` 目录双击 `启动Agent.bat`（默认 `http://127.0.0.1:8000/`）
- 当前为本地调试外链；公网部署后会换成正式地址

**[打开 IVD Agent（本地）](http://127.0.0.1:8000/)** ← 需先启动后端，否则无法打开
