# CAN：标识符、拓扑、帧与位时序

> 系列目录：[嵌入式驱动面试手册](/pages/blog/2026-10-20-嵌入式驱动面试手册)

高速 CAN（ISO 11898-2）是多主差分总线。逻辑 0 是显性，逻辑 1 是隐性。任一节点发显性，总线就是显性。ID 从高位开始比，先发出 0 的节点获胜，所以 ID 越小优先级越高。

| 状态 | 逻辑 | CANH | CANL | 差分 |
|---|---|---|---|---|
| 隐性 | 1 | 约 2.5 V | 约 2.5 V | 约 0 V |
| 显性 | 0 | 约 3.5 V | 约 1.5 V | 约 2 V |

控制器的 TX/RX 是单端逻辑，TJA1050、TJA1042 一类收发器才变成差分。

两端各一只 120 Ω，断电后 CANH–CANL 约 60 Ω。中间节点不要再加终端。1 Mbit/s 时支线宜 ≤ 0.3 m，干线经验长度约 25 m；500 kbit/s 时干线约 100 m，支线尽量 ≤ 1 m。设备离干线远，就把干线拐过去，不要拉长支线。

## CAN ID

11 位 ID 是 `0x000`–`0x7FF`，29 位是 `0x00000000`–`0x1FFFFFFF`。它是帧的名字和优先级，不是站地址。两个节点不要用同一个 ID 发不同数据，数据场会打出位错误。

| ID | 谁发 | 含义 |
|---|---|---|
| 0x080 | 故障节点 | 急停，能压过周期状态 |
| 0x100 / 0x110 | 主控 | 广播命令 / 点名写参数 |
| 0x201–0x20F | 各从机 | 周期状态，低 4 位是节点号 |
| 0x300 以上 | 从机 | 日志，优先级最低 |

`0x100`（`001 0000 0000`）和 `0x180`（`001 1000 0000`）同时发时，第 4 位分出胜负：前者发显性，后者退出。

只接收 `0x200`–`0x20F` 时，掩码用 `0x7F0`。STM32 写入过滤器高半字要左移 5 位。

CANopen 把 11 位分成 4 位功能码和 7 位节点号，心跳是 `0x700 + 节点号`。J1939 的 29 位里，位 28–26 是优先级，位 7–0 是源地址。

## 控制器模式

| 模式 | 行为 |
|---|---|
| 正常 | 发送、接收、ACK、错误帧 |
| 静默 | 只听，ACK 不驱动到总线 |
| 环回 | 忽略 ACK 错误，用于自检；CANTX 仍会输出 |
| 静默环回 | 内部把 TX 反馈到 RX。不想影响现网时让收发器待机 |

环回能通，不能代替正常模式下的双节点测试。

## 四种帧

数据帧、远程帧、错误帧、过载帧。远程帧没有数据场，RTR 为隐性。错误主动节点发 6 个显性加 8 个隐性界定符，其他节点叠加上去后显性段常见 6–12 位。过载帧电平相同，但只出现在帧间空间，不增加错误计数。

标准帧和扩展帧可以共线。基址相同时，先比标准帧的 RTR 和扩展帧的 SRR，标准数据帧在这一位已经获胜。

经典 CAN 整帧一个波特率，数据 0–8 字节。CAN FD 的 FDF 为隐性；BRS 为隐性时，从该位采样点切到数据段波特率，CRC 界定符再切回，ACK 仍用标称波特率。DLC 9–15 表示 12、16、20、24、32、48、64 字节。数据不超过 16 字节用 CRC-17，更长用 CRC-21。经典节点看到 FD 帧会发错误帧，总线上不能混有关不掉错误的老节点。数据段到 2 Mbit/s 以上要开收发器延迟补偿（TDC）。

## 采样点

```
N = 1 + BS1 + BS2
波特率 = CAN时钟 / [(BRP+1) × N]
采样点 = (1 + BS1) / N
```

bxCAN 寄存器里的 TS1、TS2 比 TQ 个数小 1。时钟 42 MHz、500 kbit/s：预分频 6，BS1=11，BS2=2，N=14，采样点约 85.7%。≤500 kbit/s 常用约 87.5%，1 Mbit/s 常用约 75%。硬同步发生在 SOF；帧内重同步每次最多调 SJW 个 TQ。

Bus-Off 是发送错误计数超过 255。最后错误码 3 几乎总是没有 ACK，或波特率完全不对。
