# PWM：占空比、互补与死区

边沿对齐、向上计数、PWM 模式 1：

```
频率 = f_tim / [(PSC + 1) × (ARR + 1)]
占空比 = CCR / (ARR + 1)
```

计数器小于比较值时输出有效电平。有效电平是高还是低由极性位决定。极性反了之后，比较值越大，引脚上的高电平越短。中心对齐时向上和向下各走一遍才是一个周期，频率还要除以 2。

比较值为 0 时占空比是 0。比较值等于 ARR 时是 ARR/(ARR+1)，不是严格的 100%。舵机是 50 Hz 下大约 0.5–2.5 ms 的脉宽，先把周期设成 20 ms，再改比较值。

TIM3 时钟 84 MHz、20 kHz、25%：PSC = 0，ARR = 4199，CCR = 1050。

互补输出和死区只有高级定时器（TIM1/TIM8）有。死区是硬件插在“一个关、另一个开”之间的时间，不是把两路比较值手动错开。168 MHz 且不分频时，DTG = 84 落在编码的第一档，死区是 0.5 µs。

主输出使能 MOE 必须打开，否则高级定时器所有通道被关掉。刹车会硬件清除 MOE，故障消失后要重新置位。
