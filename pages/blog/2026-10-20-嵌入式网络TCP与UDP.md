MCU 侧常见结构是 MAC、外接 PHY、带变压器的 RJ45。排查按层走：PHY ID、Link、描述符、ARP、ICMP、TCP。百兆 RMII 的 REF_CLK 是 50 MHz；MAC 和 PHY 必须共用这一个时钟，来源可以是 MCU、PHY 或外部晶振。PHY ID 在寄存器 2 和 3，读出来全 0 或全 1 时先查地址、复位和 MDIO。

同一子网发 IP 之前要 ARP。跨网段 ARP 的是网关。判断方法是本机 IP 和目标 IP 分别与掩码相与，结果相同才算同一子网。

## UDP

无连接数据报。首部 8 字节：源端口、目的端口、长度、校验和。一次发送对应一个报文，接收端一次读回这个报文，边界还在。不编号、不重传。以太网 MTU 1500 时，UDP 载荷上限 1472 字节。

UDP 本身没有握手。DHCP 的 Discover、Offer、Request、Ack 是跑在 UDP 上的四步应用流程。

## TCP

字节流。两次 write 可能被合并成一次 read，仪器协议要自己加长度或定界符。

| 步骤 | 主动打开 / 主动关闭 | 被动一方 |
|---|---|---|
| 发出 SYN | SYN_SENT | LISTEN → SYN_RCVD |
| 握手完成 | ESTABLISHED | ESTABLISHED |
| 发出 FIN | FIN_WAIT_1 → FIN_WAIT_2 | CLOSE_WAIT |
| 最后的 FIN/ACK | TIME_WAIT | LAST_ACK → CLOSED |

服务端在 SYN_RCVD 就要占用一个连接块。RST 直接拆连接，不进 TIME_WAIT。可靠靠序号、累计确认和超时重传；连续 3 个重复 ACK 会快重传。接收窗口是流量控制，拥塞窗口是另一套限制，实际发送量取较小值。

LwIP 收到数据后必须调用 `tcp_recved`，否则窗口保持 0，连接看起来像卡死。`tcp_write` 之后要 `tcp_output`。回调里 `p == NULL` 表示对端已经 FIN。交互命令可以关 Nagle，避免小包被攒住。

ping 通只说明 ICMP 往返正常，不能说明 TCP 端口开着。M7 上 DMA 缓冲还要处理 Cache，见 [Cache 与 DMA](/pages/blog/2026-10-20-Cache与DMA一致性)。
