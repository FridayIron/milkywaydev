# 定时器：时钟倍频与输入捕获

> 系列目录：[嵌入式驱动面试手册](/pages/blog/2026-10-20-嵌入式驱动面试手册)

通用定时器是带预分频的计数器，加上比较、捕获和从模式。更新中断做周期任务，输出比较产生 [PWM](/pages/blog/2026-10-20-PWM)，输入捕获量脉宽。

## 时钟

STM32F4 / APM32F4 上，定时器挂在 APB，但时钟不总是等于 APB：

- APB 分频系数是 1：定时器时钟 = APB
- 分频系数不是 1：定时器时钟 = 2 × APB

168 MHz 系统、APB1 = 42 MHz 时，TIM2 的时钟是 84 MHz。SysTick 用内核时钟或它的 8 分频，不要套用这条规则。

向上计数：

```
计数频率 = f_tim / (PSC + 1)
更新周期 = (PSC + 1) × (ARR + 1) / f_tim
```

从 0 计到 ARR，一共 ARR+1 个计数。84 MHz、PSC = 83、ARR = 999 时，更新周期是 1 ms。

ARR 和比较值默认有预装载，要等更新事件才生效。初始化时可以软件触发一次更新来装载预分频，同时把由此产生的更新标志清掉。只开 NVIC 不开定时器中断使能，不会进中断。TIM1 的更新中断号不是 TIM2 那种单一通道。

清标志时用赋值清掉指定位。对状态寄存器做读改写，可能把刚置位的其他标志一起清掉。

## 输入捕获

上升沿把计数器锁进比较寄存器，再捕下降沿，差值乘计数周期就是高电平时间。中间若溢出，要补上 ARR+1。打开输入滤波，否则毛刺会被当成边沿。误差至少 ±1 个计数。

周期刚好是设置值两倍时，优先检查有没有把定时器时钟当成 APB、漏了乘 2。
