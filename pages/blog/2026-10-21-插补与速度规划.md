步进电机只认脉冲。数控意义上的**路径插补**决定多轴如何走出直线/圆弧；**单轴速度规划**决定一根轴如何 Acc→Const→Dec。口语里有人把「刷新脉冲周期」也叫插补——那是速度层。本文按数控标准区分二者。

## 两类不要混

| 类型 | 解决什么 | 典型算法 | 现网 MCU 直驱 |
|---|---|---|---|
| 轨迹 / 路径插补 | 多轴同步走出直线、圆弧 | Bresenham、DDA | **无** |
| 速度 / 脉冲时序 | 单轴从静止加速到巡航再减速 | 梯形/S 曲线、速度表 | **有** |

```text
路径插补：目标路径 → 每周期各轴 Δpulse → 各轴发脉冲
单轴速度：目标步数 → Acc/Const/Dec → TIM 改 ARR → STEP
```

现网直驱常见路径：应用命令 → 速度表 + 相位机 → ISR 改 ARR → DRV8711。表值近似微步 pps；短行程会裁剪加减速段。多电机是命令级串行/并行 + 各轴独立 TIM——「推手与盘同时动」是调度并行，**不等于**路径插补。

## 什么时候才需要真正的插补

| 场景 | 要不要路径插补 |
|---|---|
| 推手到坐标 / 相对步进 / 盘到工位 | 否（单轴点到点 + 速度表） |
| 推手与盘「一起动」 | 否（并行，非联动轨迹） |
| 两直线轴必须走出斜线/平面直线 | **是** |
| 平面圆弧、复杂轮廓 | **是** |

盘电机转到下一孔，物理上走过圆弧，控制上只有 θ 一维。走圆弧形机构 ≠ 软件圆弧插补。

**落地判断**：只有产品要求「两个及以上自由度在运动中必须满足几何比例/曲线」，才上路径插补。

## Bresenham 直线

假想 X、Z 从 A 到 B 必须沿斜线（不能先抬后移）。若仍发两次独立 Move，空间轨迹不是直线 AB。

第一象限且 X 为主轴（dx ≥ dy ≥ 0）：

```
err = 2*dy - dx
重复 dx 次：
  发一步 X
  若 err > 0：发一步 Y，err = err + 2*dy - 2*dx
  否则：err = err + 2*dy
```

(10,3) 初始误差 -4，Y 的 3 步摊在 10 步 X 里，偏差不超过半步。DDA 用累加器溢出，多轴和圆弧更直接。量产通常是：路径插补器 → 各轴速度整形 → 脉冲发生器；现网只有后半。

## 节拍 ΔN ≠ N 条短 Move

插补节拍（如 1 kHz）只负责「这一小段时间各轴该分多少脉冲」。整段轨迹共用**一条**进给速度曲线，拍与拍首尾相接。

| | N 条短 Move | 插补 + 一条 F(t) |
|---|---|---|
| 启停 | 每条都可能 Acc/Dec | 整段只加减速一次 |
| 体感 | 一顿一顿 | 一条连续斜线 |

T=1 ms、某拍 ΔN=20 → 约 20000 pps；下一拍继续，不回到 0。粗插补在 MotionTask，精插补由定时器均匀发 STEP。浮点规划不要放进定时器中断。

## 前瞻 Look-ahead

插补管一段路径内怎么分脉冲；前瞻管多段首尾相接时拐角要不要每次刹到 0。

| 级别 | 段边界 | 适合 |
|---|---|---|
| 0 | 每段减速到 0 | 定位、注射泵、转盘。现网常态 |
| 1 | 固定或查表衔接速度 | 曲率变化不大的连续轨迹 |
| 2 | 曲率约束 + 双向传播 | 数控、切割 |

现网单段 Move / 盘 goto 段末本要停稳；时序命令之间常有业务等待。只有「连续折线且不允许段段停稳」时才谈前瞻。

三层速记：① 路径插补（现网无）② 单段速度规划（现网有）③ 多段前瞻（现网用不上）。急停独立于前瞻，见 [RTOS 线程与多轴](/pages/blog/2026-10-21-RTOS线程与多轴)。
