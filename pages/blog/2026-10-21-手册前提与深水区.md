# 手册前提与深水区

> 系列目录：[嵌入式驱动面试手册](/pages/blog/2026-10-20-嵌入式驱动面试手册)

下面这些条目原手册的方向是对的，面试时要主动补上前提，避免被追问成“绝对成立”。

## 需要限定的表述

| 原表述 | 更稳妥的说法 |
|---|---|
| 1 Mbit/s 干线约 25 m | 支线通常 ≤ 0.3 m。干线经验值在 25–40 m，还受线缆、节点数和终端质量影响 |
| 日志用高 CAN ID 所以优先级低 | 优先级只由 ID 数值决定。高 ID 是应用层故意让日志让路，不是协议分类 |
| I2C 100 kHz 就用 4.7 kΩ | 总线电容接近 400 pF 时，4.7 kΩ 的上升时间可能超标。电阻下限看灌电流，上限看 `tr / (0.8473 × Cb)` |
| SPI 模式差 1 就整体错 1 位 | 常见是错位或首 bit 错，低速时也可能时好时坏，不能说必然错 1 位。读命令标志以从机手册为准 |
| RMII 只能有一个时钟源 | MAC 和 PHY 必须共用同一个 50 MHz REF_CLK，来源可以是 MCU、PHY 或外部晶振，但全链路只能有一个 |
| 死区 DTG=84 在 168 MHz 下是 0.5 µs | 按 STM32F4 第一档编码，84 × (1/168 MHz) ≈ 500 ns。换系列先查 DTG 分档表。死区越大越不容易直通，但会吃掉有效占空比 |
| 栈顶掩码 `0x2FFE0000` | 只适合 SRAM 从 `0x20000000` 起、大约 128 KB 的型号。F7/H7 不能套用 |
| `.data` 拷贝边界 | 来自链接脚本的 `_sidata`、`_sdata`、`_edata` |
| 接收前 Invalidate | 必须在启动 DMA 之前做完。DMA 已经在写之后再作废，可能丢掉刚写入的数据 |
| 定时器时钟 ×2 | 是 STM32F1/F4 一类的典型时钟树。换系列先查参考手册 |
| NDTR | 是数据项个数。半字宽度时 NDTR=10 是 20 字节 |

9 个 SCL 脉冲后 SDA 仍为低：继续发脉冲，必要时给从机断电再上电。

## 追问时怎么往下答

**UART。** 误差大约超过 2%–3% 会误码。115200 乱码要查时钟能不能被波特率整除，不只说“配错了”。RS485 切回接收必须等 TC。自动收发电路省掉 GPIO，高速长线仍要核对切换延迟。

**I2C / SPI。** 设备变多、电容变大，上拉要减小，同时不能小到灌电流超标。SPI 的 `tCSS`、`tCSH` 在时序图里，不在寄存器说明正文里。

**CAN。** 位填充从 SOF 到 CRC 序列，连续 5 个相同位插一个反相，用来给重同步提供边沿。节点频繁掉线而线束正常时，查 TEC/REC 是否已经 Bus-Off。

**ADC。** 采样是给内部采样电容充电。高阻输入要加长采样时间，或加跟随器。过采样每 4 倍大约多 1 位，前提是噪声接近白噪声。32 次不是无限提高精度。

**看门狗。** 不要在定时器中断里喂狗：主循环死了，中断还在喂，狗永远不咬。IWDG 用 LSI，启动后软件关不掉。WWDG 用 PCLK，喂早了或喂晚了都会复位。

**Modbus RTU。** 帧尾是 3.5 个字符时间的静默，不是固定帧头。多字节是大端。半双工同样要等 UART 的 TC 再切方向。

**低功耗。** Sleep 只停 CPU。Stop 停时钟但保留 SRAM。Standby 几乎断电，SRAM 丢失，唤醒类似复位。要保留现场或快速恢复时用 Stop。

**volatile。** 对寄存器必须加，保证每次从内存访问。它不保证原子性，也不代替内存屏障。改寄存器某一位用读-改-写加掩码；有“写 1 清零”语义的位不能裸或、裸与。

**Linux 字符设备。** `file_operations` → 设备号 → `cdev` → 设备节点。用户指针必须 `copy_to_user` / `copy_from_user`。设备树靠 `compatible` 匹配后进 `probe`；`status = "okay"` 才会用。优先用 `devm_` 资源，失败时看 `dmesg` 里是 `-EPROBE_DEFER` 还是 `-ENODEV`。
