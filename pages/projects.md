# 项目经验

## 项目一：全自动免疫分析仪 iStar2000 (POCT)

**时间**：2023.08 - 至今 | **职责**：负责整机下位机功能设计

### 项目介绍

iStar2000 全自动免疫分析仪整机全组件下位机开发，涵盖级联轨道、进样模块、样本移液模块、试剂针模块、双轴机械抓手、旋转开盖/摇匀模块、试剂盘（恒温冷藏）、孵育盘（恒温加热）、光电采集（PMT/HCT）、条码识别等十余类模块。

### 技术选型

- **硬件**：六块 APM32F407 + FPGA / LPC5506 / STM32F103 / 外挂厂商模块（CAN 通信）
- **软件**：MCU（C/C++）前后台方式，业务层功能基于 Qt-C++/Lua 混合命令控制平台
- **通信**：CAN / 232 / 485 / FSMC 协议控制及多模块挂载

### 核心功能

- Bootloader（STM32F103 / LPC5506 / APM32F407ZG）
- 多运动模式步进电机控制
- 温度控制（PID）
- 整机错误故障恢复处理、整机参数缓存处理
- 各组件应用层功能设计

### 关键业绩

- 完成整机全部下位机功能，推进软件平台化建设，完善时序平台
- iStar2000 从 0 到 1 成功发布量产，百台设备投入医院稳定使用
- 荣获 2024 年先进个人

## 项目二：液动样本臂

**时间**：2022.07 - 2023.07 | **职责**：负责模块软硬件功能设计

### 项目介绍

由三轴（XYZ/XRZ）机械臂、液体驱动系统和样本缓冲盘三个部分组成的高精度微量液体转移机械臂，最小移液量 5ul，CV < 3%。涉及液面检测、液面跟随、吸空检测、凝块堵塞检测、管路漏气检测、耗材清点、反应杯扫描、样本就近转移、参数保存、MCU 异常自恢复等功能。

### 技术选型

- **MCU**：LPC1778
- **RTOS**：ThreadX
- **通信**：CAN 命令解析

### 核心工作

1. 梯形加减速算法控制步进电机，多线程实现多电机协同运动，实现闭环控制及失步检测
2. 卡尔曼滤波、均值滤波及状态判断提高液面等检测功能的抗干扰能力
3. 吸液液面跟随；卡尔曼、最小二乘法拟合曲线和快排处理数据，实现凝块堵塞检测及管路漏气检测
4. 耗材清点中采用二分法缩短检测时间
5. 绘制原理图、步进电机控制电路板 PCB、输出通信协议、部件（需求）设计方案、程序流程图等

### 关键业绩

- 重构 MAGLUMI X6-X8「液动样本臂」下位机裸机程序，修复 CAN 通信异常、液位及凝块检测失误等 BUG
- 完成 ThreadX 软件平台的液动样本臂功能开发，实现原理样机模块全功能正常运行
- 完成「Snibe 一次性吸头检测工装」下位机编写，2022 年 8 月投入使用，至今未收到运行异常反馈
- 荣获 MAGLUMI X6 项目研发团队·研究工作中最大贡献奖，特记一等功
